⬇ 下载小土豆杀毒
文件名：小土豆杀毒压缩包.zip 大小：约 36.7 MB
⚠️ 下载前必读
这是一个个人练习项目，用 Python + Tkinter 写的。它没有正规厂商的代码签名证书， 所以 Windows 可能会有安全提示，属于正常现象。

怎么用

  1. 点上面的绿色按钮，把 小土豆杀毒压缩包.zip 下载下来
  2. 好消息：这是 .zip 格式，Windows 自带就能解压 —— 右键点它 → 「全部解压缩」就行，不用装 7-Zip
  3. 解压后会看到 小土豆杀毒压缩包 文件夹，里面有 小土豆杀毒.exe，还有 小组件（下载器和游戏）、图片、Necessary documents
  4. 双击 exe 启动。如果双击没反应，就双击包里的 「打不开的时候用！.bat」
💡 那个 .bat 是干嘛的？
它会自动找同目录下的 exe。所以你把整个文件夹搬到哪都能用， 不会出现"移动位置后打不开"的情况。

它能做什么

🛡️ 三层检测
⏸️ 暂停可疑进程
🔍 SHA-256 病毒库
📁 文档批量改写监测
⌨️ 全局热键呼出
🚀 开机自启
热键：Ctrl+Alt+S 呼出窗口　·　Ctrl+Alt+Q 彻底退出
点窗口右上角 × 只是缩到后台继续守着，不是退出。

遇到拦住了怎么办

  • 双击没反应 / 文件不见了 —— 被杀软或 Windows 智能应用控制拦了。打开杀软的隔离区，恢复并加白名单。
  • 弹"无法验证发布者" —— 这个程序没有签名证书，正常的。点"更多信息 → 仍要运行"（如果按钮是灰的，那是智能应用控制，只能关掉它）。
  • 弹 UAC"是否允许更改" —— 点"是"，程序需要权限才能监控进程。
  • 第一次启动很慢 —— 单文件 exe 要先解压自己到临时目录，等 1~3 秒正常。
